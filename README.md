## Getting Started (for anyone cloning this repo fresh, including the Auditor)

### Prerequisites
- Node.js (v20 or later recommended)
- Java (comes bundled with Android Studio, no separate install needed)
- Android Studio, if you want to run the app on an emulator or device

Check what's installed:
```
node -v
npm -v
java -version
```

### Run it as a website (fastest way to preview, no Android Studio needed)
```
npm install
npm run dev
```
Then open the printed `localhost` link in a browser.

### Run it as an actual Android app
```
npm install
npm run build
npx cap sync android
npx cap open android
```
This opens the project in Android Studio. From there, press the Run button (green triangle) with an emulator or connected device selected.

Note: there is no `requirements.txt` in this project, that is a Python-specific file. This is a Node.js project, so `package.json` (already committed) plays the same role, `npm install` reads it automatically and installs the exact same dependencies for anyone who runs it.

## Mobile App

Android app for on-site fieldwork: single skeleton entry and a quick visual check.

### Stack
- Node.js
- Vite (bundler)
- React + TypeScript
- Capacitor (wraps the web app into an Android app)

### Current project structure
This is the equivalent of an HTML/CSS/JS project, just with React and TypeScript instead of plain files. Currently sits at the repo root:

```
index.html          same role as a plain HTML project's index.html
src/
├── main.tsx         entry point, mounts the app (like a <script> tag would)
├── App.tsx           the main component, top of the UI tree
└── assets/           images and static files
public/               static assets served as-is
android/               native Android project, generated by Capacitor, don't hand-edit much here
package.json           lists dependencies (the npm equivalent of requirements.txt)
capacitor.config.ts    Capacitor's settings (app name, ID, etc.)
vite.config.ts         bundler config
```

### Day-to-day commands
```
npm run dev            run as a normal website locally, fastest way to preview changes
npx cap sync android    push web build into the Android project
npx cap open android    open in Android Studio to run on emulator or device
```
