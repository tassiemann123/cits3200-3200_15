# Optional reference models

Place the optional model files in this directory using these exact names:

- `skeleton_pre-cut.glb`
- `female_skeleton.glb`

The application still builds and runs in landmark-only mode when these files are absent. The GLB files are excluded from Git. The `skeleton_pre-cut.glb` model is licensed under the
Sketchfab Free Standard licence, which does not allow it to be shared as a stand-alone file,
so each user downloads it from the Sketchfab page (see the main README, Attribution section).
